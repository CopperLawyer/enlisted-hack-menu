## 🧩 About

**Enlisted Companion** is a curated list of Enlisted open-source tools:

- **Overlays** — on-screen helpers, layout notes, minimap viewer, squad tracker
- **Quality-of-Life Helpers** — loadout catalog, weapon manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Squad Tracker — monitor squad positions on a minimap
- Show Hitboxes — visualize hitboxes in practice mode
- Replay Notes — record and review match runs
- Playback Speed — adjust replay speed for study (0.1x to 5x)

### Wallhack
- Loadout Catalog — browse weapons, uniforms, and vehicles
- Custom Skin Notes — organize soldier cosmetics
- Solid UI Markers — improved visibility for objectives

### Aimbot
- Practice Mode Notes — segment study on any map
- Gravity Flip Control — manually switch gravity in editor
- Jump Buffer Notes — chain complex maneuvers in the editor
